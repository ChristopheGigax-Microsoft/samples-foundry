# Demo samples

This repository contains demo samples shared during customer sessions.
Customers can return here after a demo to find the code and instructions.
Internal colleagues can also use these samples to prepare demos, learn, or
contribute new examples.

## Find a sample

Samples are grouped by technology, with a separate folder for each demo or agent.

```text
samples/
`-- foundry/
    `-- agent-hosted-foundryiq-webiq/
```

### Foundry

| Sample | Status |
| --- | --- |
| [Hosted agent with Foundry IQ and Web IQ](samples/foundry/agent-hosted-foundryiq-webiq/) | Deployed; document and web retrieval verified |

Each sample folder should include its own README explaining what it demonstrates,
the prerequisites, and how to run it.

## Contribute

Place new samples under `samples/<technology>/<sample-name>/`.
Use short, descriptive folder names and include setup and run instructions.
Do not include credentials, secrets, or customer data.

These samples are for learning and demos, not production-ready solutions.
